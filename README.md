# Practice4 — Машина состояний, идемпотентность и наблюдаемость

Учебная веб-служба на C#, моделирующая процесс бронирования переговорной комнаты с выдерживанием повторной доставки событий, частичных сбоев и компенсациями.

## Возможности

- Машина состояний (7 состояний) с переходами по событиям
- Идемпотентность по ключу — повторы не меняют состояние
- Компенсация при сбое шага «Выдать доступ» (отмена бронирования)
- Сквозной идентификатор корреляции во всех логах и ответах
- Проверки здоровья: liveness и readiness
- Метрики: счётчики переходов, повторов, компенсаций, гистограмма задержки

## Запуск

```bash
cd csharp/src/Practice4
dotnet run
```
